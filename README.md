# Trabajo-Final-Aprendizaje-de-Maquinas
Predicción del bajo desempeño en razonamiento cuantitativo de estudiantes en Antioquia mediante Machine Learning

Aplicación desarrollada para la Maestría en Ciencia de Datos de la Universidad Pontificia Bolivariana (UPB).
 
Autor:
Daniel Felipe Lezcano Ríos
 
Modelo:
Random Forest balanceado ajustado
 
Objetivo:
Identificar estudiantes con riesgo de bajo desempeño en pruebas Saber PRO en razonamiento cuantitativo a partir de variables académicas y socioeconómicas, como insumo para tomar decisiones preventivas sobre estos estudiantes antes de presentar la prueba.
